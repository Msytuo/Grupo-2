# Grupos aleatorios

Este es un programa muy simple que coge un grupo de trece alumnos y los mezcla aleatoriamente en tres grupos de tres y un grupo de cuatro.


## Instalación

Para instalarlo solo debe descargar el archivo.zip y ejecutarlo en visiualstudio con el comando:

```bash
  python .\prueba.py
```
    
## Comentario

En este programa estamos utilizando la biblioteca "random".
